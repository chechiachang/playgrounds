# playgrounds

Meta repo for `chechiachang` playground/workshop projects.

Purpose:
- one place to discover playground/workshop repos
- track each repo as a git submodule pointer
- enable bulk update of all repos from one root

## Submodules

- [`argocd-playground`](./argocd-playground) — Argo CD experiments.
- [`chef-playground`](./chef-playground) — Chef automation playground.
- [`circle-ci-playground`](./circle-ci-playground) — CircleCI pipeline tests.
- [`elasticsearch-playground`](./elasticsearch-playground) — Elasticsearch demos/labs.
- [`etcd-playground`](./etcd-playground) — etcd learning and tests.
- [`gemini-playground`](./gemini-playground) — Gemini API/app experiments.
- [`genai-playground`](./genai-playground) — Generative AI prototypes.
- [`go-rag-playgound`](./go-rag-playgound) — Go-based RAG experiments.
- [`istio-playground`](./istio-playground) — Istio service-mesh labs.
- [`k8s-playground`](./k8s-playground) — Kubernetes experiments.
- [`k8sgpt-playground`](./k8sgpt-playground) — K8sGPT usage/tests.
- [`kafka-playground`](./kafka-playground) — Kafka streaming playground.
- [`llm-o11y`](./llm-o11y) — LLM observability experiments.
- [`mcp-playground`](./mcp-playground) — MCP protocol experiments.
- [`n8n-playgound`](./n8n-playgound) — n8n workflow playground.
- [`nextjs-playground`](./nextjs-playground) — Next.js experiments.
- [`rag-workshop`](./rag-workshop) — RAG workshop materials.
- [`speckit-playground`](./speckit-playground) — Speckit experiments.
- [`terraform-playground`](./terraform-playground) — Terraform labs.
- [`vault-playground`](./vault-playground) — HashiCorp Vault experiments.
